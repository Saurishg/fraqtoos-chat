Image Generation & Editing
🎨
Text → Image
Generate images with FLUX Schnell, FLUX Dev, SDXL, Juggernaut XL, or SD 1.5.
/image <prompt>
✏️
Edit Image (FLUX Kontext)
Attach a photo, cycle to ✏️ Edit mode, then describe your change.
attach → ✏️ Edit
🪄
Avatar in Scene (PuLID-FLUX)
Attach your face photo, cycle to 🪄 Avatar, then describe a scene.
attach → 🪄 Avatar
🔄
Face Swap (insightface)
Attach two images: set one as 🔄 Source (face) and one as 🎯 Target.
attach → 🔄/🎯
⚡
Size & Model Controls
Choose image size (512/768/1024) and model from the input bar dropdowns.

Memory & Conversations
🧠
Persistent Memory
Save facts the AI recalls in every future conversation. Enable auto-extract to let it save facts from your messages.
/remember <fact>
🗑
Forget
Delete specific memories by keyword. Or open 🧠 Memory panel and ✕ any entry.
/forget <keyword>
💾
Auto-Save Conversations
Every reply is auto-saved to disk. Conversations survive page refresh and are listed in the sidebar.
🏷
Auto-Title
phi4 automatically generates a short title for each conversation after the first reply.
🔍
Conversation Search
Type in the sidebar search box to search all saved conversation titles and content.
Chat Tools
✏
Edit & Resend
Click any of your past messages to edit the text and resend from that point.
↺
Regenerate
Click ↺ on any bot reply to regenerate the response with the same input.
🔊
Read Aloud (TTS)
Click 🔊 on any bot message to have it read aloud. Click again to stop.
⧉
Copy Message
Click ⧉ to copy any bot reply's raw text to clipboard.
💡
Follow-up Chips
After each reply, phi4 suggests 3 follow-up questions as clickable chips.
⟳
Clear Context
Resets AI memory for the current chat while keeping messages visible on screen.
Ctrl+Shift+X
🔎
In-Chat Search
Search and highlight text across all messages. Navigate with ▲▼ buttons.
Ctrl+F
↓
Export Chat
Download the current conversation as a Markdown (.md) file.
📚
Prompt Library
Save and reuse your favourite prompts. Press Ctrl+S in the input to save the current text.
Ctrl+S to save
⚙
System Prompt
Set a persistent system instruction for every message in the current session.
System & UI
🖥
GPU VRAM Widget
Live GPU VRAM used/total and utilisation % in the topbar. Updates every 10 s. Hover for per-GPU detail.
🟢
Status Light
Green = Ollama up. Red = server unreachable. Hover to see Ollama / Claude / Search / Image status.
🔢
Token Counter
Approximate token usage for the current context. Turns amber above 30 k tokens.
📱
PWA — Install as App
Add to your home screen / desktop. Works offline for the UI shell.
◀
Collapsible Sidebar
Click ◀/▶ to hide/show the sidebar. State is remembered across sessions.
